# 数字彩助手

一个可以直接「添加到 iPhone 主屏幕」的数字彩 PWA：双色球、大乐透、福彩3D、排列5、快乐8 的开奖号码、冷热统计与娱乐性号码推荐。

- **在线地址**：<https://xiaomayi1899.github.io/lucky-numbers/>
- **自动更新**：GitHub Actions 每 10 分钟抓取官方开奖数据并重新部署
- **自动刷新**：页面打开时每 60 秒检查一次新数据，推荐号码每 5 分钟自动重新投票
- **公式集成**：61 个公式模型独立评分并投票，展示每个号码的票数、参与投票的公式清单，以及最终一注
- **离线可用**：Service Worker 缓存应用壳与最近一次开奖数据
- **零依赖**：纯静态 HTML / CSS / JavaScript，不需要服务器、数据库或构建工具

> 推荐号码由统计模型随机生成，**不能预测开奖结果**。仅供个人学习与娱乐，理性购彩，未满 18 周岁禁止购买彩票。

## iPhone 安装（添加到主屏幕）

1. 用 **Safari** 打开 <https://xiaomayi1899.github.io/lucky-numbers/>
2. 点底部工具栏的「分享」按钮
3. 选择「添加到主屏幕」→ 右上角「添加」
4. 以后从主屏幕图标打开，就是全屏 App；断网也能查看缓存的开奖数据

> 必须用 Safari 的「添加到主屏幕」才能获得全屏 PWA 体验；微信内置浏览器不支持。

## 功能

| 彩种 | 开奖 | 推荐 | 统计 |
| --- | --- | --- | --- |
| 双色球 | 红球 6 + 蓝球 1 | 最终一注 + 备选一注 | 红/蓝球冷热、遗漏、形态 |
| 大乐透 | 前区 5 + 后区 2 | 最终一注 + 备选一注 | 前/后区冷热、遗漏、形态 |
| 福彩3D | 3 位数字 | 最终一注 + 备选一注 | 分位置冷热、遗漏、和值 |
| 排列5 | 5 位数字 | 最终一注 + 备选一注 | 分位置冷热、遗漏、和值 |
| 快乐8 | 20 个号码 | 选十最终一注 + 备选一注 | 冷热、遗漏、区间形态 |

推荐引擎由 **61 个公式模型**组成，分 6 类：频率与贝叶斯、遗漏与生存、转移与关联、形态与组合、时间序列、分布与优化。每个模型对号码独立评分，并给最看好的前 3 名各投 1 票；汇总票数后按票数选号，再做奇偶、区间、和值、连号等形态约束，最终得到“最终一注”。页面会展示：

- 每个号码获得的票数（球下方和票数卡片中）
- 61 个公式的名称、公式、当前看好的号码
- 最终一注与备选一注

这些模型只是不同角度的统计描述，**不会提高中奖概率**，也不构成任何购彩建议。

## 数据来源

- 中国福利彩票官方公开接口：<https://www.cwl.gov.cn/>
  - 双色球、福彩3D、快乐8
- 中国体育彩票官方公开接口：<https://www.sporttery.cn/>
  - 大乐透、排列5
- 备用镜像：<https://datachart.500.com/>
  - GitHub Actions 的海外服务器通常无法直连上述官方接口，脚本会自动回退到 500.com 公开历史页；单个来源失败时保留上一次成功数据。

`scripts/fetch_data.py` 仅使用 Python 标准库，在 GitHub Actions 中运行：

1. 优先抓取官方接口，失败时回退到 500.com
2. 合并写入 `data/lottery.json`（保留最近 150 期）
3. 提交变更并使用 GitHub Pages 重新部署

网站本身不经过任何第三方数据代理，开奖数据来自官方公开接口或公开历史页面。

## 本地运行

```bash
# 1. 抓取/刷新数据（可选，仓库中已带最新数据）
python scripts/fetch_data.py

# 2. 启动本地静态服务器
python -m http.server 8080

# 3. 浏览器打开 http://127.0.0.1:8080/
```

> Service Worker 需要 HTTPS 或 localhost 才会启用；局域网 `http://192.168.x.x` 访问时页面正常，但离线缓存不会注册。


## 部署到自己的 GitHub Pages

1. Fork 或新建仓库，推送本目录到 `main`
2. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**
3. 在 **Actions** 中手动运行一次 `更新开奖数据并部署 Pages`
4. 地址为 `https://<你的用户名>.github.io/<仓库名>/`
